詠鵝
==

**駱賓王**

### 想想看

閱讀下面的詩歌，然後回答問題。

```
我游泳

像一艘白色遊艇。

我走路

八字腳不很好看。
所以我
最喜歡的是池塘，
最怕的是上岸！
```

1. 詩中的「我」是指池塘中的哪一種動物？在上圖的○內打✓。
2. 這種動物的叫聲是怎樣的？和同學一起模仿，看誰模仿得  
   最像。

---

### 作者簡介

駱賓王，字觀光，唐代著名詩人。  
他的父親早逝，他小時候跟着母親投靠親友，過着貧困的生活。駱賓王自小很聰明，才華出眾，相傳他七歲便能寫詩，大家都稱他為「神童」。

[PAGE::8]
寫作背景

《詠鵝》相傳是駱賓王七歲時創作的，詩中描繪了他在水邊所見的美景。駱賓王用簡單易懂的文字，捕捉了白鵝的聲音、外貌和動作，寫出白鵝彎着脖子，一邊游泳，一邊向天高歌的姿態，從而歌詠白鵝。

|  |  |
| --- | --- |
|  | Yǒng é 詠①鵝 Luò Bīnwáng 駱賓王 |

```
é é é  
鵝鵝鵝②,  
Qū xiàng xiàng tiān gē  
曲項③向天歌。  
Bái máo fú lǜ shuǐ  
白毛浮綠水,  
Hóng zhǎng bō qīng bō④  
紅掌撥清波。
```

注釋：

1. 詠：用詩歌來描繪或讚揚某一事物。
2. 鵝鵝鵝：鵝的叫聲「哦哦哦」。另一說為小孩子發現鵝時，高興地指着鵝大叫：「鵝！鵝！鵝！」
3. 曲項：彎曲的頸項。「項」是頸的後背，音ㄩㄥˊ卷ㄅㄨˇxìàng。
4. 清波：清澈的水波。

[PAGE::9]
### 知識加油站

鵝的聽覺很靈敏，警覺性強，遇到陌生人或其他動物時，牠就會高聲鳴叫來警告陌生人，有些鵝甚至用嘴或雙翼來進行攻擊。

讀詩時，留意駱賓王用「鶉鶉鶉」三個字，生動地表達了甚麼情景。

還要邊讀邊想像一下詩中色彩豐富的畫面啊！

畫雞
==

唐寅

想想看

搜集公雞的圖片，貼在  內。

作者簡介

唐寅，字伯虎，明代著名畫家和文學家。他年少時已經才華出眾，二十九歲時在鄉試中考得第一名，但他無意當官，後來漫遊華中、江南等地，以賣畫為生。

寫作背景

唐寅畫功了得，不論山水、人物、花鳥也難不倒他。有一次，唐寅畫了一隻大公雞，並在畫中的空白處寫下了《畫雞》這首「題畫詩」。詩中描繪了公雞威風的形象，並歌頌公雞平時不輕易啼叫，一叫則驚人的特點。有說唐寅是以畫中的公雞比作自己。

注釋：

1. 寅：音粵仁普yín。
2. 裁：剪裁、縫製。音粵才普cái。
3. 走將來：走過來。「將」是語助詞，表示動作的開始。
4. 平生：平日、平時。
5. 輕言語：輕易說話。
6. 千門萬戶：很多住戶、家庭。

#### 知識加油站

雞在中國文化中有吉祥的意義。因為公雞能夠在天亮時啼叫，按時叫醒人們，因此象徵守信和準時。

內容賞析
----

本詩是一首題畫詩，語言淺白地描繪了一隻神氣的公雞。首句描寫公雞頭上的紅冠，第二句再描寫公雞渾身雪白的羽毛，又以紅色對比白色，使公雞形象鮮明。第三句令讀者心生疑問，第四句則點出公雞的特點，氣勢雄渾，感情豪邁，兩句詩句形成強烈對比，使人印象深刻。

蜂 羅隱
----

**想想看**

在( )內畫出你最喜歡的昆蟲，並說說原因。

---

**作者簡介**

羅隱原名羅橫，是唐代著名文學家，他在年青時曾經多次參加科舉考試，但全部都不成功，自此他改名為羅隱。他寫的詩歌和文章簡單易明，內容與時事和社會問題有關。

---

**寫作背景**

羅隱在這首詩中，通過讚美蜜蜂，說出自己對社會現象的看法。蜜蜂在辛勞地採花釀蜜後，蜂蜜卻被人們取去，令羅隱想起當時的農民，他們在辛勞耕作後，成果卻被奪走了，羅隱因而對農民生同情，並通過寫作來表達感受。

**作者簡介**

這首詩出自漢代的樂府詩，作者身份已不能考究。漢樂府是漢代的一個官方機構，專門收集民間歌謠，製作成樂章，在宮中唱誦，讓皇帝和官員瞭解民間疾苦。

蓮葉雖然生長在池塘，但由於它的表面有一層透明的膜，因此不會沾上池塘的泥土。

14

[PAGE::21]
寫作背景

江南有很多湖泊，每年夏、秋是採蓮的好時節，湖泊上長滿了蓮葉和蓮花，魚兒在蓮葉之間游來游去。這時候，年青男女會一邊唱歌，一邊採蓮。這首詩便是他們唱的歌謠。

注釋：

1. 江南：泛指長江以南的地方。一說指秦漢時期的江南，專指今湖北南部和湖南、江西一帶。
2. 可：適宜、正好。
3. 採：採摘。
4. 何：多麼。
5. 田田：蓮葉圓整，就好像「田」字一樣。「田田」是蓮葉相疊，形容水面上荷葉茂密、相連的樣子。
6. 戲：嬉戲。

你覺得詩中活潑的魚兒，像不像在遊樂場上愉快地跑來跑去的小孩？

元日 王安石
------

**想想看**

農曆新年的其中一個習俗是貼揮春。你知道哪些揮春上的吉祥話？在□內寫一寫。

### 作者簡介

王安石，字介甫，號半山，宋代著名政治家和文學家。他自小聰穎，勤奮好學，下筆成文，後來當上宰相，主張推行新法，改革國家。

王安石從政時期的詩歌，內容多圍繞政事和反映時弊，語言激烈尖銳。到了晚年退隱後，改寫詠物詩和寫景詩，更注重文詞的雕琢。王安石的散文成就也很高，不但觀點鮮明，而且議論透徹，因此被列為「唐宋古文八大家」之一。

[PAGE::24]
Yuán rì

元日(①)
=====

Wáng Ànshí 王安石

Bào zhú shēng zhōng yí suì chú (②),

爆竹聲中一歲除

Chūn fēng sòng nuǎn rù tú sū (③).

春風送暖入屠蘇

Qiān mén wàn hù tóng tóng rì,

千門萬戶瞳瞳(④)日，

Zǒng bǎ xīn táo huàn jiù fú (⑤).

總把新桃換舊符。

寫作背景
----

王安石擔任宰相初期,就積極推行改革,希望解決當時宋代的內憂外患。王安石寫下此詩時,正是他開始推行新法後的第二年,因此本詩亦被視作寄託了他對國家將來的樂觀祈願,正如人們對新的一年充滿幹勁一般。

[PAGE::25]
### 知識加油站

古時放爆竹的目的是驅鬼迎神，後來漸漸變成了慶祝節日、婚宴和慶典等必不可少的環節，在農曆新年放爆竹更有送舊迎新之意。不過現時香港已經嚴禁市民燃放煙花爆竹。

#### 注釋：

1. **元日**: 農曆正月初一。
2. **一歲除**: 一年過去了。
3. **屠蘇**: 酒名。古人會於正月初一喝屠蘇草泡的酒，並把渣滓掛在門上，用來驅邪。
4. **曈曈**: 太陽升起，由暗轉明的樣子。音 (童) tóng。
5. **桃、符**: 桃和符都指「桃符」。這是古代一種繪有神像、掛在門上辟邪的桃木板，演變至今，成為春聯。

清明 杜牧
=====

想想看

你知道清明節有甚麼習俗嗎？這些習俗有甚麼意義？

作者簡介

杜牧，字牧之，號樊川居士，唐代詩人和散文家。杜牧生於書香世家，家中歷代為官。杜牧亦於二十五歲考中進士，踏上仕途。由於他個性剛直，不善逢迎，仕途並不得意。杜牧的詩歌內容以詠史、抒懷、反映時弊為主，風格豪爽而具感染力，成就頗高，與李商隱並稱「小李杜」。

---

寫作背景

杜牧寫下這首詩歌的時候正值清明佳節。古時候的清明節尤為隆重，是家族聚首拜祭的大日子。然而在這個節日氣氛濃厚的日子，杜牧卻獨自在外，於是寫下此詩，寄託孤單之情。

Qīng míng

清明①
===

Dù Mǔ 杜牧

Qīng míng shí jié yǔ fēn fēn(2),

Lù shàng xíng rén yù duàn hún(3).

Jiè wèn(4) jiǔ jiā hé chù yǒu,

Mù tóng yáo zhǐ xìng huā cūn(5).

[PAGE::29]
注釋：

1. 清明：二十四節氣之一，大約在公曆四月五日前後，這天有掃墓和踏青的習俗。
2. 紛紛：形容細雨下得很密。
3. 欲斷魂：非常傷心，好像失去魂魄的樣子。
4. 借問：請問。
5. 杏花村：有人說是指杏花深處的村莊，也有人認為是村莊的名字。

知識加油站

中國的傳統祭祀節日除了有清明節外，還有寒食節。寒食節有二千多年的歷史，人們在這天不會生火煮食。由於寒食節與清明節日子相近，後來便漸漸合併成一個節日。

### 內容賞析

本詩生動地描寫出清明時節的景象。首兩句描寫清明節雨水連綿的天氣和行人哀傷的神態，營造出傷感的氣氛。後兩句承接「欲斷魂」，指出詩人向牧童問路，尋找酒家休息，以舒緩情緒。末句的「杏花村」給人美麗的聯想，淡化了清明雨中掃墓的愁懷，讓詩人在期待的氣氛下前行。
